# AI 公众号排版器 - 智能对话生成系统

## 项目简介

这是一个基于AI的智能公众号排版系统，采用三列布局设计，通过对话方式帮助用户生成符合微信公众号排版要求的内容。系统支持多轮对话交互，用户可以与AI助手讨论想法，AI会逐步完善内容并生成结构化的Markdown格式文本，最终转换为可直接粘贴到公众号编辑器的HTML代码。

## 功能特点

### 🎯 三列布局设计
- **左侧**：AI对话区 - 与AI助手进行多轮对话，完善文章内容
- **中间**：Markdown编辑区 - 查看和编辑AI生成的Markdown内容
- **右侧**：预览区 - 选择排版风格并实时预览最终效果

### 💬 智能对话交互
- 支持多轮对话，AI会根据用户反馈逐步完善内容
- 自然语言交互，无需学习复杂的排版知识
- AI会提出有针对性的问题来帮助用户明确需求

### 📝 Markdown编辑
- 自动生成结构化的Markdown格式内容
- 支持用户手动修改和完善内容
- 实时预览Markdown转换效果

### 🎨 多种排版风格
- **AI科技风格**：深邃科技蓝配色，适合技术类文章
- **极简商务风格**：沉稳商务灰蓝配色，简洁留白设计
- **专业学术风格**：学术深蓝配色，严谨学术风格
- **创意设计风格**：创意紫配色，富有视觉冲击力

### 🔐 安全的API管理
- API密钥本地存储，不会暴露在代码中
- 首次使用时输入，后续自动保存
- 支持随时修改API密钥

### 📱 响应式设计
- 适配不同屏幕尺寸
- 移动端友好的交互体验
- 流畅的动画和过渡效果

## 使用指南

### 1. 首次使用设置
1. 打开 `new-layout.html` 文件
2. 首次使用时会弹出API密钥设置框
3. 输入您的API密钥（目前支持硅基流动API）
4. 点击"保存"按钮，密钥将安全存储在本地浏览器中

### 2. 创建文章内容
1. 在左侧对话框中输入您的文章主题或想法
2. AI助手会与您进行多轮对话，逐步完善内容
3. 对话过程中，AI会自动将初步结果填充到中间的Markdown编辑区

### 3. 编辑和完善内容
1. 在中间的Markdown编辑区查看AI生成的内容
2. 根据需要手动修改和完善内容
3. 点击"确认内容"按钮确认最终版本

### 4. 生成排版
1. 在右侧选择合适的排版风格
2. 点击"生成排版"按钮，AI会将Markdown转换为符合公众号要求的HTML
3. 在右侧预览区查看最终效果

### 5. 复制和使用
1. 点击"复制HTML"按钮，将排版好的内容复制到剪贴板
2. 直接粘贴到微信公众号编辑器中，格式不会丢失
3. 也可以点击"复制Markdown"按钮获取Markdown格式内容

## 技术实现

### 前端技术栈
- HTML5 + CSS3：响应式布局和现代UI设计
- Tailwind CSS：快速构建美观的界面
- Vanilla JavaScript：实现所有交互功能
- Font Awesome：提供精美的图标

### AI集成
- 使用硅基流动API调用DeepSeek-V3模型
- 实现多轮对话上下文管理
- 支持Markdown到HTML的智能转换
- 根据不同风格应用对应的排版规则

### 数据存储
- 使用localStorage存储API密钥
- 对话历史保存在内存中，刷新页面会清空
- 无需后端服务器，纯前端实现

## 常见问题

### Q: 如何更换API密钥？
A: 点击页面顶部的"API设置"按钮，输入新的密钥并保存。

### Q: 对话历史会保存吗？
A: 对话历史仅在当前会话中保存，刷新页面后会清空。如需保存内容，请及时复制Markdown内容。

### Q: 生成的HTML可以直接粘贴到公众号吗？
A: 是的，生成的HTML已经过优化，完全兼容微信公众号编辑器，可以直接粘贴使用。

### Q: 支持哪些排版风格？
A: 目前支持AI科技、极简商务、专业学术和创意设计四种风格，每种风格都有独特的配色和排版特点。
